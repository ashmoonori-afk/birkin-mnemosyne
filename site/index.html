01 / KEEP THE MAP. OPEN THE NOTE.

Carry context, not the whole vault.

A new session needs a way back to earlier work. Loading every note upfront spends context on details that may have nothing to do with the task.

A complete INDEX at startup

The opt-in INDEX keeps every “when to read → which document” route available. Large maps can use complete topic views. Going over the soft budget warns; it does not silently remove a route.

Read the INDEX guide ↗

Details when the task needs them

Exact triggers open complete documents. Task-bound startup reads return every lexically matched document in full. Ordinary recall uses multilingual BM25, usage-driven decay and zone priorities. Lexical matching is not a semantic guarantee.

A handoff for the next session

Immutable project/task checkpoints keep work, decisions, open items, open questions, the next step and links. Scoped startup includes the complete latest capture. MCP clients manage capture and resume calls; Hermes has opt-in lifecycle callbacks.

Labels and a preview-first start

Readable namespace:value labels filter eligible notes without becoming ranking terms. mnemosyne init previews organization and imports before an explicit apply. It does not automatically merge, archive or delete your notes.

Your folders stay intact

From 0.7.1, ordinary recall includes visible nested Markdown folders. Hidden files, caches and links stay excluded. Zones keep the complete relative parent; archive and checked undo retain the original subpath and bytes. Version 0.7.2 also keeps same-name notes in different folders searchable.

Read memory from the terminal

The published package includes search, list and show. These commands inspect memory without counting a use or changing usage ranking. Repeatable label filters narrow the eligible notes before ranking or pagination.

02 / MEASURED, WITH THE SMALL PRINT

Measured changes.
With explicit limits.

These are documented experiments, not a promise about your vault or your agent's answers.

0.8.0

Cross-language recall: in the research setup with a judge and translated queries, Hit@5 rose from 298 to 1,028 of 1,432 unseen questions in six languages (3.45x, October 25, 2026). The key-only setup was not measured.

Off by default: MNEMOSYNE_RERANK_API_KEY turns on reranking, and translated queries also need MNEMOSYNE_RERANK_TRANSLATOR. Without a key, or with MNEMOSYNE_RERANK=off, recall stays on your machine.

When on, a query costs an estimated $0.0081 and about 4 s.

0.8.0

0.7.2: same-name notes stay searchable

On 20,000 public round-two documents, a known answer appeared in the first two results for 537/1,011 heldout questions, up from 270/1,011 (26.71% to 53.12%, +26.41 percentage points). There were 274 paired gains and seven losses.

The already-indexed development slice fell from 231/405 to 224/405. A preregistered source-family interval could not be computed because some strata had only one family. The owner explicitly waived that criterion and shipped on the paired evidence; it is not claimed as passed. Questions were reused and alternative-answer coverage remains incomplete.

The cost of reading small notes

Small-note combined task costs are 199–221 tokens for Sol (12/12 cost more than the full original) and 229–432 for Claude (0/12 cost more). These are separate measurements, not task accuracy on the large corpus.

Historical v0.6.0 measurement

The earlier fictional large-note result was 45,128 → 1,781 o200k_base whole-startup tokens. There was no accuracy gain. On its separate small-note fixtures, all 12 Sol tasks and 7 of 12 Claude tasks cost more than reading the full original.

Read the historical result and limits ↗

Handoffs and labels add context

The Windows-shaped handoff fixture grew from 163 to 919 estimated tokens (+756). The separate label fixture grew from 1,052 to 1,076 (+24). These use ceil(UTF-8 bytes / 4), not a model tokenizer. They are different fixtures: never add them into a universal total.

Optional retrieval has trade-offs

Semantic mode is opt-in and not the recommended default: some test slices lose to the core. The Linux replay measured a 0.38 → 80.24 MB install, excluding 669.1 MB of raw and compact model files. Its largest indexing-memory addition was 163 MB, above the 150 MB budget. These are not service-level guarantees.

Host-written query expansion costs about 115–200 output tokens per widened search and about twice the ranking time. Earlier tokenizer experiments did not establish a general Korean recall gain. The separate 0.7.2 result above is an indexing fix, not proof of answer accuracy or universal multilingual coverage.

04 / START WITH PLAIN FILES

Install. Preview. Then apply.

Python 3.10 or newer. The core stores and searches notes without a model, API key or runtime dependency.

Install the core

pip install birkin-mnemosyne==0.9.0

mnemosyne init --vault my_vault
mnemosyne init --vault my_vault --apply

The first init command is a read-only preview. Inspect the plan before applying. Without --vault, init uses MNEMOSYNE_VAULT when set, otherwise the current directory.

View the package on PyPI ↗

Connect an MCP client

uvx --from "birkin-mnemosyne[mcp]==0.9.0" \
  mnemosyne-mcp --vault ~/mnemosyne

The MCP extra downloads the official SDK on first launch. Configure this stdio command in your client. Point clients at the same vault to share memory.
