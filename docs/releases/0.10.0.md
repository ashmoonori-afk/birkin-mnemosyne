# Release notes v0.10.0

With a rerank key set, recall now returns nothing when the hosted judge finds no relevant note: on 337 held-out messages the benchmark vault cannot answer, a note still surfaced for 116 instead of 325 at 1,000 notes (64% fewer), while 781 of 784 right answers stayed in the top five.

## What's new

- `KibitzerAdapter.recall()` and the MCP tool `memory_kibitzer_candidates` drop notes whose merged judge score is below `crosslingual.RELEVANCE_FLOOR` (0.5). An empty result means the judge ran and found nothing worth showing; `fallback` stays `None`.
- The pairwise step runs only on the notes that pass, so a question uses 6.7 judge requests on average instead of 23.3.
- `min_relevance` on `crosslingual.rerank()` and `select_crosslingual()`; pass `0` to keep all five notes.
- `benchmarks/unanswerable` adds a frozen set of 560 unanswerable messages in six languages, kept separate from the older question sets, which are unchanged.

## Measured (held-out test split, November 3, 2026)

| Check | Without floor | With floor |
|---|---:|---:|
| Unanswerable messages that surfaced a note, 160 notes | 325 / 337 | 117 / 337 |
| Same, 1,000 notes | 325 / 337 | 116 / 337 |
| Same, 10,000 notes | 327 / 337 | 109 / 337 |
| Right note in top five, 972 answerable questions, 1,000 notes | 784 | 781 |
| Notes shown per answerable question, 1,000 notes | 4.25 | 1.00 |
| Six-language set, 2,400 questions, right note among five | 1,602 | 1,581 |
| Unseen six-language holdout, 1,432 questions | 1,028 | 1,012 |
| Median `recall()` time, 1,000 notes, 40-question sample | 2.4 s | 1.6 s |
| Cost per question at the discounted catalog price / list price | $0.00042 / $0.0083 | $0.00036 / $0.0071 |

The ship limits were fixed before any measurement and all passed: at least 60% fewer unanswerable messages surfacing a note (64.0%, 64.3% and 66.7% at 160, 1,000 and 10,000 notes; grouped 95% lower bounds 58.8%, 59.0% and 61.2%), at most 2 points lost on the answerable retrieval set (worst 0.41), no exact-keyword answer lost, and at most 2% of hits lost on the two six-language sets (1.31% and 1.56%). [Full results and method](https://github.com/ashmoonori-afk/birkin-mnemosyne/blob/main/benchmarks/unanswerable/RESULTS.md).

## Limits

- The floor needs the judge. Without `MNEMOSYNE_RERANK_API_KEY`, recall is unchanged: it stays local and still returns BM25 candidates for every question.
- Messages that share a note's subject but ask for a fact it lacks are the hard case: about half of them (114 of 216 at 1,000 notes) still surface that note. Off-topic messages almost never do (2 of 121).
- The unanswerable set was written by a model and checked by a second model; the vault is the synthetic retrieval benchmark vault.
- The two six-language sets reuse the five notes the 0.8.0 study selected with translated query views, each scored in a one-card request. The package default has no translated views.
- Prices are those of November 3, 2026 for `sionic-ai/jev-omni`; the catalog showed a 95% discount that may end.

## Upgrade

```sh
python -m pip install -U "birkin-mnemosyne==0.10.0"
python -m pip install -U "birkin-mnemosyne[mcp]==0.10.0"   # with the MCP server
```

Hermes Agent users should also install the plugin from the `v0.10.0` checkout as described in [integrations/hermes/README.md](https://github.com/ashmoonori-afk/birkin-mnemosyne/blob/v0.10.0/integrations/hermes/README.md). The Hermes provider does not use the hosted judge, so its behaviour is unchanged.
