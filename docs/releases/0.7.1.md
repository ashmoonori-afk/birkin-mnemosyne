# birkin-mnemosyne 0.7.1

This release brings visible nested Markdown folders into ordinary recall and
publishes the terminal inspection commands that previously required a checkout.
The core remains dependency-free and needs no model or API key to store or
search notes.

## Nested folders without moving your notes

- Discover visible Markdown recursively, including nested imports and folders
  with spaces or Unicode names. Hidden files, cache directories, symlinks and
  Windows reparse points remain excluded.
- Use complete relative parent paths for zones, labels, INDEX routing, startup,
  curation and MCP. Archive preserves the original subpath; checked journal
  undo restores exact original paths and bytes.
- Resolve duplicate filename stems by newest modification time, with a warning
  and deterministic POSIX-path tie-break. Existing stem-based interfaces remain.
- Keep archived descendants out of active search and curation, including
  case-variant archive names. Linked mutation destinations are refused.

## Read memory from the terminal

- `mnemosyne search`, `list` and `show` return the same JSON fields as their MCP
  counterparts without recording use or changing usage ranking.
- Repeat `--label namespace:value` to require all labels before ranking or
  pagination. `list` reports label counts for the complete eligible set.
- `mnemosyne --version` matches the package version. `mnemosyne undo` uses the
  checked journal for init, fold and review transactions.
- Commands share `--vault`, then `MNEMOSYNE_VAULT`, then the server's default
  vault; init keeps its current-directory fallback. Quoted `~` paths expand.

## Reliability

Supported source extensions are case-insensitive without renaming originals.
Corrupt INDEX state reports errors without inventing orphan classifications.
Related links respect actual Markdown section boundaries, long filenames use
short atomic staging names, and startup calls accept omitted paths when a scoped
handoff or other startup source exists. Invalid MCP vaults report errors without
corrupting protocol output.

## Install

```sh
python -m pip install "birkin-mnemosyne==0.7.1"
# Optional MCP server:
python -m pip install "birkin-mnemosyne[mcp]==0.7.1"
```

The bundled Hermes plugin is 0.2.2 and pins core 0.7.1. Use the documented
Hermes plugin manager; do not install directly into a managed Hermes environment.
The OpenClaw example also pins core 0.7.1. Neither instruction upgrades an
existing host automatically.

Nested discovery does not imply an accuracy improvement. Existing public
measurements, their separate corpora and their limitations remain unchanged.
Private real-corpus recall results are not part of this release.
