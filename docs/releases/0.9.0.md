# Release notes v0.9.0

The Hermes Agent memory provider adds `birkin_memory_forget` and `birkin_memory_restore` for preview-by-default, reversible note archival without changing recall, ranking, the MCP tool set, or local-only operation.

## What's new

- The Hermes provider adds `birkin_memory_forget` and `birkin_memory_restore`, sharing the core archive and restore implementation; both default to preview and move files only when `confirm=true`.
- `birkin_memory_forget` moves an exact target note to `_archive/` and returns a vault-relative archive path so `birkin_memory_get_note` and `birkin_memory_restore` can address that exact archive file even if another writer later creates a newer same-name note.
- `Mnemosyne.rezone(..., dry_run=True)` validates destination collisions and zone caps without changing the file or its index entry, and `birkin_memory_restore` uses this path for previews.
- The MCP tool `memory_forget` keeps its existing `allowed=false` / `unknown slug` result for missing notes after moving onto the shared core; Hermes cleanup returns its own not-found error.

## Safety and limits

- `birkin_memory_forget`, `birkin_memory_restore`, and `birkin_memory_remember` run only when both the provider and calling agent context are `primary`; subagents and other contexts are refused.
- Target selection requires an exact index key, vault-relative path, or unambiguous stored title; fuzzy matches and ambiguous titles are refused.
- Forgetting is soft archival, not hard deletion: the file stays under `_archive/`, remains readable via `birkin_memory_get_note`, is excluded from ordinary search and lexical prefetch, and keeps its title and slug reserved so `birkin_memory_remember` still refuses the same title.
- Protected notes (negative-polarity notes, identity/preference types, and notes that are both filed and linked, including Hermes notes in `knowledge/` whose body contains `[[wikilinks]]`) are refused with `allowed=false` and `archived=false`.
- The curation cap (`max(2, ceil(0.20 * active_notes))` and at most `active_notes - 1`) remains enforced, so the sole remaining active note cannot be forgotten, and destination collisions or refusals leave files intact.
- Recall, ranking and the MCP tool set are unchanged. The Hermes provider still makes no network calls and needs no API key; the opt-in hosted reranking from 0.8.0 is not reachable from it.

## Upgrade

```sh
python -m pip install -U "birkin-mnemosyne==0.9.0"
python -m pip install -U "birkin-mnemosyne[mcp]==0.9.0"   # with the MCP server
```

Hermes Agent users should also install the plugin from the `v0.9.0` checkout as described in [integrations/hermes/README.md](https://github.com/ashmoonori-afk/birkin-mnemosyne/blob/v0.9.0/integrations/hermes/README.md).
